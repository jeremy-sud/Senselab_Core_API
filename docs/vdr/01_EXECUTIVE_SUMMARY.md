## Qué Está Comprando

Un **motor ERP enterprise-grade** listo para producción que incluye:

### Núcleo ERP (95 Controllers, 98 Modelos, 175 Validaciones)

- Nómina y RRHH con compliance CAJA costarricense
- Módulo de Transporte especializado (único en el mercado)

### 10 Servicios de Inteligencia Artificial
- OCR de Facturas (Gemini Vision) — 92% precisión
- Clasificación CABYS automática — 98% precisión
- Credit Scoring de clientes
- Detección de anomalías contables — 95% precisión
- Predicción de inventario

- Análisis financiero

- **Multi-tenancy** con base de datos aislada por empresa (Spatie)

- **Webhooks** event-driven con HMAC-SHA256
- **API versionada** (v1/v2) con Sunset headers
- **Read Replicas** para escalabilidad de lectura
- **Redis Cache** + ETags HTTP
- **OpenTelemetry** distributed tracing
- **Laravel Horizon** para monitoreo de colas

### DevOps Production-Ready
- Docker + Docker Compose (dev, staging, production)
- Kubernetes manifests (Kustomize con overlays)
- 9 pipelines CI/CD en GitHub Actions
