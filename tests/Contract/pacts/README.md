# Pact Contract Files

This directory contains Pact contract JSON files generated by consumer tests.

These files define the expected interactions between consumers (frontend apps)
and the Ursol CAST API provider.

## Workflow

1. **Generate**: Run consumer tests → writes `.json` pact files here
2. **Verify**: Run provider verification → reads pact files, replays against real API
3. **Share**: In a full Pact workflow, these files would be published to a Pact Broker

## Files

Generated files follow the naming pattern:
`{consumer}-{provider}.json`

Example: `UrsolCastFrontend-UrsolCastApi.json`
